Known limitations
  • Long functions are detected but not structurally extracted by the safe text-level remediator (a TODO comment is inserted instead).
  • One residual dead-code finding may remain after remediation.
  • Current prototype is Python-only.

How It Works

  1. Scan — Walk the sample Python codebase and parse each file into an AST.
  2. Detect — Five detectors identify hardcoded secrets, long functions, code duplication, missing error handling, and dead code.
  3. Prioritize — Findings are ranked by severity (critical → high → medium → low).
  4. Remediate — Safe text-level patches are applied to a separate output/patched/ copy — the original codebase is never modified.
  5. Validate — The patched copy is re-scanned and results are compared before and after.

About This Prototype

This is a self-contained local developer tool created for the IBM Bob 2.0 Hackathon. It runs entirely on your machine — no external APIs, no cloud services, no credentials, and no personal data. The built-in sample_codebase/ is a synthetic Python project designed to exercise all five technical-debt categories supported by the pipeline.

The full pipeline is also available from the command line: 

python main.py scan
python main.py fix
